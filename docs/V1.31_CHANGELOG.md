# V1.31

周记录与分析报告最终优化版。

- 周一归档/清理改为只在应用启动或回到前台时执行。移除应用内午夜等待任务，符合“新的一周第一次打开 App 时处理”的约定，也不依赖 Android 后台定时任务。
- 周边界计算改为显式按周一回退，不受设备地区设置的每周起始日影响；首页统计和归档使用同一边界。
- 保留幂等事务顺序：先统计上一个完整的周一至周日，再写入单槽上周报告，最后清理旧原始记录；跨过多周后打开也只生成紧邻上一周的报告。
- 补全上周报告统计：正式练习、安般念/经行/护根、五盖、当下事件、五蕴、缘起、戒行复盘、每日修行、八戒自检和独立复盘均纳入报告，另显示参与统计的记录总数。
- 复盘中心的多次刷新请求改为可取消的串行结果，避免周归档完成前后的异步读取互相覆盖，保证报告卡片显示最新数据。
- 保留首页“本周”次数与分钟、各记录页“周一自动清除”提示、上周报告单独卡片、首次使用无报告文案、两类练习计时器跨入口/进程恢复和学习中心首次加载判断。
- 版本号提升为 `1.31`，`versionCode = 136`。
- 本次只更新源码与文档，不制作 APK。
