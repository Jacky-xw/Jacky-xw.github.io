# V1.29.2

学习中心与稳定性清理版。

- 阅读设置补齐行距调节，并与字体大小、页面宽度、夜间阅读一起保存到本地 `SharedPreferences`。
- “继续学习”可以回到上次分类与滚动位置；离开学习中心前会立即保存当前位置。
- 学习中心显示当前分类阅读进度和当前章节，长文章阅读时可以随时判断位置。
- 安般念内部五个入口切换后自动回到内容起点，章节目录抽屉改为可滚动，长目录可以完整访问。
- 经行计时器在离开页面后不再播放自然结束提示音；回到页面后仍保留试听和自定义音频。
- 首页刷新请求串行化，避免反复进入首页时旧统计覆盖新统计；七日统计改用日期半开区间，兼容旧的日期格式。
- 删除未被任何页面接入的旧首页占位模型、旧计时状态模型、空 Hilt 模块和旧计时引擎；不影响现有首页、练习、观察、学习中心与复盘功能。
- 删除未被 AndroidManifest 或资源引用的旧 `release-assets` 图标副本，保留 `res/mipmap-*` 正式应用图标。
- 保留首页今日反馈、今日修行顺序、今天下一步、累计练习次数和累计分钟等功能。
- 版本号提升为 `1.29.2`，`versionCode = 133`。
- 本次只更新源码与文档，不制作 APK。
