# RuruPractice V1.21

## 本版目标
让第一次使用的人能够在不反复翻阅手册的情况下，理解今天的基本修行路线，同时修正安般念计时器在切换时长/重新计时后丢失当前十六步的问题。

## 主要更新
- 新增首次使用引导：四个页面说明修行主线、安般念前四步、日间护根、五盖调节与安全边界。
- 首次使用完成状态使用 SharedPreferences 持久保存。
- 安般念默认时长调整为 20 分钟，与手册第一周的固定二十分钟安排一致。
- 修正切换安般念时长时当前 practiceStep 被重置为第 1 步的问题。
- 修正重新计时后当前 practiceStep 被重置的问题。
- 安般念页面增加“练习中遇到问题”速查：昏沉、掉举、分析过多、特殊体验。
- 保留 V1.20 的今日修行顺序、每日反馈、四念处/缘起/五蕴观察、经行、护根、五盖、戒行、八戒、学习中心与长期复盘。

## 与手册对应
- 第一周：固定时段坐二十分钟。
- 安般念：先熟悉前四步，再逐渐进入受、心、法三组。
- 五盖：识别后采用对应调节，不把五盖当成失败。
- 观修：分析过多导致直接经验模糊时回到安般。
- 特殊现象：不追逐，不据此认定证果。
