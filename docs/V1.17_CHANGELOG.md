# RuruPractice V1.17.0

本版本以《实修手册优化版》为功能基准，重点解决 V1.16 中“手册要求已经明确，但软件仍主要提供计时和记录”的问题。

## 主要更新

### 1. 安般念十六步正式进入练习界面
- 提供十六步选择。
- 按身念处、受念处、心念处、法念处分组展示。
- 每一步显示与手册对应的简明练习提示。
- 保留原有计时、暂停、完成、观察与历史记录。
- 保存记录时同时保存第几步及步骤名称。
- 界面提示：前期先练熟第一组，再逐渐练习其他三组；十六步不机械等同于四禅。

### 2. 新增经行
- 全身行走 / 脚步所缘两种入口。
- 实际计时。
- 经行观察记录与历史。
- 加入站、走、停、转、速度、与安般念衔接等核心提示。

### 3. 新增护根
- 眼、耳、鼻、舌、身、意六根入口。
- 按“接触 → 受 → 爱 → 取 → 回应”记录。
- 保存并查看历史。

### 4. 数据层
- 新增经行记录表。
- 新增护根记录表。
- Room 数据库升级到 V3；继续使用现有 fallbackToDestructiveMigration 策略。

### 5. 修习页
- 安般念
- 经行
- 护根
- 五盖
- 戒行

原有五盖、戒行功能保留。
