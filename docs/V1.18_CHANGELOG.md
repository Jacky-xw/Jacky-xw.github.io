# V1.18 更新说明

## 与《在家居士入流修行手册》的对照完善

V1.17 已经把安般念十六步、经行、护根加入应用。V1.18 继续补足手册中“理论 → 实修 → 调节 → 长期检验”的连接。

### 1. 学习中心重构
新增五个板块：
- 修行主线：四圣谛、八正道、安般念十六步、四念处、缘起、五蕴、入流方向。
- 调节工具：七觉支、昏沉/掉举时的调整、五根五力、护根。
- 四周起步：完全按手册的第一阶段安排展示。
- 长期检验：长期训练模板与三个月复盘指标。
- 安全边界：特殊体验、不适反应、回到安般、居士责任。

### 2. 修行次第进一步明确
学习内容明确强调：
- 坐禅前段以安般稳定心。
- 心稳定后，再把明显的受、心、烦恼纳入四念处。
- 缘起优先从清楚的触→受→爱→取入口观察。
- 五蕴用于检验“我、我的、我的自体”，不把概念分析当成实修本身。
- 若分析使心散乱，回到自然呼吸。

### 3. 防止误用
加入对特殊体验、过度用力、失眠/明显异常体验、生活责任受损等情况的明确提醒。

### 4. 保留 V1.17
V1.17 的安般念十六步、经行、护根、五盖、戒行及记录功能全部保留。
