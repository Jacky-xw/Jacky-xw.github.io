# RuruPractice V1.19

## 本版目标
把 V1.18 已有的练习入口进一步连接起来，让首页能够根据实际记录给出“今天下一步”的训练提示，并提供近七日的稳定性反馈。

## 主要变化
- 首页新增“今日修行反馈”：安般念、经行、护根、观察、五盖记录。
- 首页新增“今天下一步”：依据当日已有记录安排下一项练习。
- 首页新增近七日安般念、经行次数。
- 显示近七日记录中强度较高的五盖类型，作为观察线索，不作为评分。
- 扩展 PracticeRepository 的聚合读取能力。
- 保持原有手册原则：记录用于如实检查修行，不用于计算证果、境界或能力等级。
- 继续保留 V1.18 的安般十六步、经行、护根、八戒、学习中心、长期复盘和安全边界。

## 数据兼容
本版没有新增 Room Entity，因此无需提高数据库版本。
