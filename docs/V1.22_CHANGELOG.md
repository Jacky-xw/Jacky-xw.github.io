# RuruPractice V1.22.0

## 本版本修复

1. Android 目标升级到 SDK 36，应用版本号 1.22.0。
2. Room 数据库从 V3 升级到 V4：
   - V2 → V3 增加安般念步骤字段，并建立经行、护根表。
   - V3 → V4 增加戒行日期字段，并建立八戒自检表。
   - 移除 destructive migration，避免升级时无条件清空长期修行记录。
3. 修复戒行记录缺少日期导致首页无法正确统计的问题。
4. 八戒／简化日自检改为数据库持久化，重新进入页面或重启应用后仍能恢复当天状态。
5. 首页今日统计与近七日统计改为数据库范围查询，不再只从最近 100 条记录估算长期数据。
6. 安般念计时器改用系统时间戳计算经过时间，降低因协程调度、切后台等造成的计时漂移。
7. 安般念活动计时状态使用 SharedPreferences 保存，进程重建后尽可能恢复正在进行的练习。
8. 经行计时器同样改为时间戳机制，并保存活动状态；保存记录前停止计时，避免旧计时任务继续修改状态。
9. Android 15/16 边到边布局使用 safeDrawing insets，减少系统栏遮挡风险。
10. 增加可自举下载 Gradle 8.11.1 的 `gradlew`，方便没有预装 Gradle 的环境启动构建。

## 验证说明

已完成源码结构、版本配置、Room 迁移 SQL、关键持久化逻辑及 ZIP 完整性检查。
当前制作环境没有完整 Android SDK/AndroidX 依赖缓存，因此无法在本环境宣称已经完成真实 APK 编译和真机 Android 15/16 测试；打开项目后应使用 Android Studio 或具备 SDK 36 的 Gradle 环境进行最终构建与设备验证。
