# 实修日 V1.25.0

- 统一首页统计模型：安般念、经行、护根共用练习总次数；安般念与经行共用累计时长；八戒自检继续独立保存。
- 首页最近练习增加多选删除，删除源记录后统计、列表和复盘候选会随本地数据刷新。
- 修习页改用可横向滚动的标签栏，长标签、八戒自检条目和复盘关联标签不会被固定宽度吞掉。
- 收紧各记录页上下留白，改用统一内容内边距，保留滚动和底部安全区域。
- 顶层导航改为单一返回栈模式；安般念手动完成并自动写入期间也能立即返回首页。
- 安般念记录 BottomSheet 在文件级显式 opt-in Material 3 实验 API，并在自动写入未完成时禁用重复记录入口。
