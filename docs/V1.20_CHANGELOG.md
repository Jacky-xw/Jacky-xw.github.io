# RuruPractice V1.20

## 本版目标
把 V1.19 的“今日下一步”进一步落实为可理解的每日训练顺序，并让五盖记录真正连接到七觉支的调节建议。

## 主要变化
- 首页新增“今日修行顺序”：安般念 → 白天护根 → 四念处观察 → 经行 → 戒行复盘。
- 每一项根据当天是否已有相应记录显示完成状态；状态仅用于回看训练连续性，不作为评分或证果指标。
- 首页加入“戒行复盘”统计，使手册的睡前检查进入每日反馈。
- 五盖趋势由“单次强度最高”调整为“近七日出现频率较高”的类型，减少一次偶然高强度记录对反馈的影响。
- 根据近七日较常出现的五盖，给出与手册七觉支调节原则对应的具体建议。
- 昏沉提示念、择法、精进、喜并可经行；掉举提示轻安、定、舍；贪欲、瞋恚、疑分别回到受→爱、直接经验和四圣谛/安般。
- 不新增 Room Entity，继续兼容 V1.19 数据库版本 3。

## 与手册的对应
本版重点落实手册中的“标准工作日课表”“五盖处理”“四念处与经行”“睡前复盘”以及“七觉分调节”内容。
