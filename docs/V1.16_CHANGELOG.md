# RuruPractice V1.16

## 完整可运行 MVP

### 构建

- 增加 `app/build.gradle.kts`、Compose Compiler、KSP、Room 和 Hilt 配置。
- 增加 `RuruApplication` 与 `@AndroidEntryPoint`，补齐 Hilt 运行入口。
- 增加 Compose Material 主题与 Android 主题资源。

### 安般念

- 接通开始、暂停、继续、提前完成和自动完成。
- 完成后填写观察与练习后状态，并保存为 `MeditationSessionEntity`。
- 增加最近练习查询、累计次数和累计时长统计。
- 首页和修习页都展示历史记录。
- 修习页增加五盖与戒行的记录入口。

### 观察与复盘

- 增加当下事件观察表单。
- 增加五蕴拆解表单。
- 增加缘起链条（触、受、爱、取）记录表单。
- 增加复盘记录表单与历史列表。
- Repository 与 DAO 补齐对应的保存和查询方法。

### 导航与体验

- 五大页面接入真实 Navigation Compose 底部导航。
- 首页增加今日方向、统计卡片、最近练习与刷新操作。
- 学习页增加四圣谛、八正道、五蕴和缘起的入门卡片。
