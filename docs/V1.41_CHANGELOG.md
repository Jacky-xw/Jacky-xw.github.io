# V1.41.0 — 性能深度优化

## 架构审查结论（性能）
- 高频状态必须局部收集：禁止整页 `collectAsState` 订阅每秒变化的 elapsed。
- 历史列表：LazyColumn + 稳定 key/contentType + 长文折叠。
- 计时持久化：禁止 tick 写 SharedPreferences。

## 本版改动
1. **经行页**：页面壳只订 method/phase/note/history；`WalkingTimerCard` 单独订 elapsed（对齐安般念）。
2. **安般念计时卡片**：拆分为 phase/elapsed/remaining/minutes/step 分字段订阅；`TimerActions` 仅依赖 phase。
3. **首页**：SessionSummaryCard modifier 签名与调用一致（修复编译）。
4. 延续 V1.40.x：虚拟列表、CollapsibleNote、通知/计时保活既有优化。
