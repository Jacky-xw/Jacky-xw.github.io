# V1.30.1

左侧抽屉与学习入口导航统一优化版。

- 左侧抽屉增加统一的主导航入口，首页、修习、观察、学习、复盘均通过 `MainShell` 的同一顶层导航回调处理。
- 底部导航与抽屉导航复用 `navigateToTopLevel` 逻辑，统一 `popUpTo + saveState + launchSingleTop + restoreState` 行为，避免重复维护跳转逻辑。
- 学习入口不再建立独立跳转分支；从抽屉点击“学习”与点击底部“学习”使用完全相同的顶层导航逻辑。
- `MainShell` 为所有顶层页面提供统一左侧主导航抽屉和菜单入口；学习页目录抽屉中的主导航条目也复用同一回调，章节目录保持独立。
- 保留学习中心首次加载判断：仅当 `learning_content_loaded` 尚未完成时建立一次本地内容缓存，后续进入不重复执行首次加载。
- 学习内容首次缓存失败时提供重试，不会把首次加载状态误标记为完成。
- 版本号提升为 `1.30.1`，`versionCode = 135`。
- 本次只更新源码与文档，不制作 APK。

## Weekly record retention optimization
- Home practice count and minutes now use the current Monday-Sunday cycle and are labeled “本周”.
- All practice/history/review record lists (excluding Learning Center) state that records are cleared on Monday and retain only the current week.
- Added an app-start weekly rollover transaction: before clearing old raw records, it summarizes the immediately previous Monday-Sunday period.
- The same idempotent rollover runs at the next Monday boundary while the app stays open, and again when it returns from the background.
- Added a single-slot `weekly_report` Room table. A new report replaces the old one; no report history accumulates.
- Reflection Center now shows a standalone “上周分析报告” card. When no previous-week data exists it displays “首次使用无上周分析报告”.
- Both timed practice flows (安般念 and 经行) keep their active timer state across top-level navigation and process recreation; completed sessions enter the same weekly retention boundary.
- Room schema upgraded from 5 to 6 with a non-destructive migration.
