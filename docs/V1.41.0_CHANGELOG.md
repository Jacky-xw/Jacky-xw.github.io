# RuruPractice V1.41.0

## 性能优化

- 首页首次进入不再由启动预热重复执行整套 Room 数据汇总。
- 启动预热仅保留学习文本缓存与默认结束铃声的轻量预热。
- 首页首次加载由 `HomeScreen` 单独触发；生命周期返回前台时刷新，避免首次显示重复刷新。
- `GetPracticeSummaryUseCase` 复用已经计算出的本周统计，移除重复的周统计查询。
- 首页历史记录查询从无界 `Int.MAX_VALUE` 收紧为 500 条；当前版本按周执行记录留存，因此不会改变正常首页展示范围，同时避免异常数据量导致内存膨胀。
- 为高频日期/时间字段增加 Room/SQLite 索引。

## Release

- `isMinifyEnabled = true`
- `isShrinkResources = true`
- 继续使用默认 Android optimize ProGuard 配置。

## 明确保留的设计

冥想计时后台服务的可靠性策略不做省电化改造：

- MediaPlayer
- Foreground Service
- WakeLock
- Exact Alarm
- BroadcastReceiver

以上机制继续以计时可靠性、锁屏持续运行和结束提醒可靠送达为优先。
