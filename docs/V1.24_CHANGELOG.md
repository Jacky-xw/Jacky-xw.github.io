# 实修日 V1.24.0

## 本版自查与迭代

- 计时结束的引磬声通过本地 `res/raw/soft_bell.wav` 播放，并设置为提示音用途；只有自然结束会响，暂停、恢复、手动完成、重置和离开页面不会误响。
- 增加“试听引磬”入口，便于确认设备音量与播放器工作状态；退出页面会立即停止播放器。
- 安般念自动记录与“记录这一刻”继续使用同一条数据库记录，手动保存只更新观察和练习后状态。
- 为安般念、经行、护根、五盖、戒行补齐单选／多选删除；删除核心练习后首页统计会随本地数据库刷新。
- 复盘新增可选练习关联，保存练习的快照标签，不依赖云端或网络，也不会因删除原记录而产生外键错误。
- 八戒自检增加短暂防抖并改为按日期更新，避免连续勾选或输入造成重复数据库记录。
- Room 数据库升级到 V5，新增复盘关联字段，保留 V2→V3→V4 的非破坏式迁移链。
